## 1. Что за фид
- **CM.Expert** — платформа-«система учёта» дилера; отдаёт YML-фид, из него машины уходят
  на классифайды. Текущий сайт imperiummotors.ru сделан на **TradeDealer** (другая платформа).
- URL фида (YML):
  `https://media.cm.expert/stock/export/cmexpert/yml-html/all/all/bbff33615cf7f8873a9deacc06f35432.xml`
- Формат: `<yml_catalog>` → `<shop>` → `<offer>`. **156 машин**, дата генерации в корне
  (`<yml_catalog date="...">`) — фид **свежий**, не старый.

## 2. Что в фиде есть на одну машину (ФАКТЫ)
- **~10 `<param>`**: Год, Кузов, Руль, Цвет, ПТС, Двигатель (топливо+объём+мощность одной
  строкой), Привод, КПП, Поколение, Модель. Если распаковать «Двигатель» → ~12 значений.
- **10 `<picture>`** (ссылки на `avatars.avto.ru`, с фоном).
- `<price>`, `<vendor>` (бренд), `<name>`, `<model>`, `categoryId` (2=новый), `<store>`.
- **Опций как структурных тегов НЕТ.** Они зашиты в `<description>` (рекламный текст из
  Авто.ру) плоским списком вперемешку с водой. **Этот текст НЕ используем** (решение заказчика).

## 3. Ключевой вывод (почему фида не хватает)
Пример **Honda Inspire** (`/cars/new/honda/inspire/n3787643`):
- В фиде: 10 param, ~23 плоских опции в description, 10 фото.
- На сайте: ~13 характеристик (в т.ч. **Места, Длина, Ширина, Высота, Объём бака — которых в
  фиде НЕТ**), **«52 базовые опции» по разделам**, ~20 фото.
- Значит богатая карточка на текущем сайте собирается **НЕ из этого YML-фида**, а из
  **справочника по модификации** (каталог Авто.ру по коду поколения/модификации; TradeDealer
  подтягивает его и **перезаливает фото к себе** на `yc-images.tradedealer.net`).
- Из **нашего** фида реально доступно: ~12 характеристик + 10 фото. 52 опции/габариты — нет.

## 4. Открытый вопрос (блокер, ждём заказчика)
**Откуда текущий сайт тянет 52 опции по разделам + габариты + 20–30 фото?**
Варианты, которые надо подтвердить у заказчика / CM.Expert / тех, кто делал текущий сайт:
1. **API/структурный экспорт CM.Expert** (не YML, а с полями опций и ТТХ) — идеально.
2. **Каталог Авто.ру по модификации** (обогащение по коду) — как делает TradeDealer.
3. Дождаться **системы заказчика** (обещали отдельные поля, в т.ч. «фото без фона для карточки»).

## 6. Что уже сделано в `lib/feed.ts` (ветка `cars`)
`getFeedCars()` (async, кэш `revalidate:600` + React `cache()`): fetch YML → парсит `<offer>` →
массив `Car`. Реализовано: разбор `<param>`/`<price>`/`<picture>`, парс двигателя
(топливо/объём/мощность), нормализация кузова, маппинг цвета → `CarColor` кита, лого бренда,
`cardImage()` (плейсхолдер по кузову), slug из бренд+модель+id, `feedExtraById` (Поколение,
объём — для характеристик). `<description>` игнорируется.
