Badge

.badge

Статусная метка. Четыре цвета — Info / Success / Warning / Error — в двух вариантах: Surface (заливка) и Outlined (обводка).

Использование: <span class="badge badge--success">В наличии</span> · для обводки добавьте .badge--outlined.

Tag

.tag

Пилюля-метка. Card — тег на карточке (зелёный текст). Filter — удаляемый тег в фильтрах (серый текст с крестиком).

Card

Filter

Использование: <span class="tag tag--card">2026</span> · удаляемый: .tag--filter с .tag__close (Close.svg).

Indicator

.indicator

Статусная точка с подписью — компактный маркер состояния. Четыре статуса: Success / Warning / Error / Info.

В наличии В пути Продан Под заказ

Использование: <span class="indicator indicator--success"><span class="indicator__dot"></span>В наличии</span>.

Tooltip

.tooltip

Всплывающая подсказка на белом фоне с мягкой тенью. Два размера: S (10 px) и L (14 px).

Это подсказка. Это подсказка.

Использование: <span class="tooltip tooltip--l">Текст</span>. Показан на бежевом фоне, чтобы была видна тень.

Wishlist

.wishlist

Кнопка «в избранное» — сердечко-тоггл. Контур → залитое красное. На наведении — тултип. Кликните, чтобы переключить.

Использование: <button class="wishlist">…Heart-stroke…Heart-fill…</button> · активное — класс .is-active.

Comparison

.compare

Кнопка «в сравнение» — тоггл. List-Add (тёмный) → List-Check (зелёный). Тултип на наведении. Кликните, чтобы переключить.

Использование: <button class="compare">…List-Add…List-Check…</button> · активное — класс .is-active.

Slider

.slider

Трек прогресса / заполнения. Тонкая тёплая дорожка, заполнение — Heritage Green. Ширину задаёт .slider__fill.

0% · 76% · 100%

Использование: <div class="slider"><div class="slider__fill" style="width:76%"></div></div>.
