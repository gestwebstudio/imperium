## КЛЮЧЕВОЕ: система отступов хлебных крошек (только что сделана)

Шапка `position: fixed` с **переменной высотой 76/84/96** (мобайл/планшет/десктоп).
Всё завязано на переменные в **`styles/tokens.css`**:

```
--header-h: 76px;   /* высота шапки; @640→84, @1201→96. Меняешь шапку — правишь ТУТ */
--crumbs-gap-top: 40px;    /* зазор шапка→крошки; @960→50, @1920→60 */
--crumbs-gap-bottom: 20px; /* зазор крошки→ближайший элемент */
--page-top: calc(var(--header-h) + var(--crumbs-gap-top));  /* верхний padding контейнеров */
```

- **Верх** = `--page-top` (padding-top контейнера страницы). Итоговый зазор
  шапка→крошки: **40** (≤768) / **50** (960–1536) / **60** (1920). Одинаково на всех.
- **Низ** = `.ui-crumbs, .cat-crumbs { margin-bottom: var(--crumbs-gap-bottom) }`
  (глобально в tokens.css) = **20** везде. На карточке — через `car-wrap--top`
  padding-bottom (галерея — ближайший элемент).
- Почему так: шапка `fixed` не занимает места в потоке, поэтому отступ = высота
  шапки + зазор. **Плюс: поменяешь высоту шапки → правишь одну строку `--header-h`,
  зазоры не поедут.**
- Почистил хардкоды `padding-top`/`margin-bottom` крошек в `catalog.css`,
  `car.css`, `trade-in.css` — теперь всё через переменные.

Контейнеры крошек по группам страниц (все используют `var(--page-top)`):

## Рабочие заметки

  не «на глаз». Осторожно: шапка авто-прячется при скролле (`is-hidden`) и есть
  анимация входа страницы (`.page-transition`) — мерить в устоявшемся состоянии,
  высоту шапки брать её `getBoundingClientRect().height`.
