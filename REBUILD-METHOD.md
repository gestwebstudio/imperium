# Метод рерайта вёрстки (ветка `rebuild`) — обязательный чеклист для КАЖДОГО блока

Презентационный слой пересобираем заново по макетам Figma: **mobile-first, fluid,
на единых брейках, с чисткой легаси**. Начинку (данные/логику/анимации/токены/примитивы)
НЕ трогаем. Ниже — как делать каждый блок. Эталон, собранный по этому методу: галерея
машины (`app/catalog/[slug]/car.css`, коммит «Галерея машины: рерайт mobile-first»).

## Константы

- **8 артбордов:** `390 / 480 / 640 / 768 / 960 / 1200 / 1536 / 1920`. Брейки в CSS —
  **min-width** ровно на этих числах. Никаких off-by-one (`481/641/961/1201`).
- **Боковой отступ контента = `var(--gutter)`** (20/20/30/40/40/40/60/60). Контейнер блока:
  `max-width: var(--layout-max); margin-inline: auto; padding-inline: var(--gutter)`.
  Легаси `home-wrap`/`--page-gutter` в переверстанных блоках не используем.
- **Радиусы — токен `var(--radius-current)`** (styles/tokens.css: 12/12/14/16/22/26/30/30
  по брейкам). Не хардкодить, если значение совпадает с токеном.
- **Шрифты/цвета — токены кита** (`--font-*`, `--fs-*`, `--color-*`, `--type-*`). Точные
  значения сверяем в Figma через `get_variable_defs`.

## Цикл работы над блоком (по шагам)

1. **Разобрать текущее.** Прочитать CSS+разметку блока, вслух коротко доложить «что не так»:
   чужие брейки, резина в обратную сторону (desktop-first `max-width`), мёртвые правила,
   врущие комментарии. Это отправная точка для пересборки.
2. **Снять числа из Figma.** MCP-сервер Figma, **fileKey `bERRa0eUHmPImiBdiP62UR`**.
   - `get_metadata` — размеры/позиции (x/y относительно родителя; x фрейма = боковой отступ);
   - `get_variable_defs` — токены шрифтов/цветов/радиусов на ноде;
   - `get_screenshot` — глазами (структура, что где).
   Снимаем числа на **всех 8 артбордах** блока (1920 обычно уже свёрстан — сверяемся).
3. **Собрать заново mobile-first.** База = 390, растём вверх через `min-width`. Размеры и
   отступы — **резина `clamp`/сегментами по парам артбордов** с числами макета (как отступы
   trade-in). **Размеры шрифтов ШАГАЮТ** на брейках (точные значения макета), между брейками
   держатся. Между парой артбордов линейная интерполяция:
   `calc(A + (100vw - Wlow) * (B-A)/(Whigh-Wlow))`.
4. **Чистка.** Снести старый desktop-first каскад и мёртвый CSS этого блока целиком —
   не патчить поверх. Гуттер → `--gutter`. Радиусы → `--radius-current`.
5. **Механику не переписываем.** JS/хуки/keyframes/анимации/лайтбоксы переносим и
   перевешиваем на новую разметку. (Пример: карусель `Gallery.tsx` + PrimeReact-лайтбокс
   остались как были.)
6. **Проверка ЗАМЕРАМИ в браузере** (не на глаз): dev на :3000, in-app Browser →
   `resize_window` + `javascript_tool` с `getComputedStyle`/`getBoundingClientRect` на всех
   8 артбордах И между ними. Обязательно `documentElement.scrollWidth <= clientWidth`
   (нет горизонтального скролла). Плюс скриншот для глаза.
7. **Показать заказчику** таблицу замеров (значение vs макет по брейкам), спросить спорные
   места. После «ок» — **коммит блока** (сообщение по-русски: что было не так → что стало).

## Что НЕ трогаем на этой странице

- Блоки **«рекомендованные авто»** (`CarsSection`) и **«контакты»** (`Contacts`) —
  переподключаются отдельно, в макетах их нет. Не удалять, не верстать.
- Общие компоненты (`Badge/Button/Crumbs/Wishlist/Comparison/PriceBlock`, иконки) — берём
  как есть, правим только раскладку/обёртку блока.

## Ноды Figma — карточка машины (артборд → node)

`390 → 1165:13265` · `480 → 991:3149` · `640 → 971:4908` · `768 → 959:4313` ·
`960 → 932:6218` · `1200 → 932:4966` · `1536 → 932:3874`. (1920 — уже свёрстан.)
Внутри артборда: галерея = `Frame 1000005916`; шапка-заголовок = `Frame 1000006003`;
левая колонка (характеристики/комплектация/цена) = `Frame 1000005998`.
**1200 — десктоп-раскладка** (как 1536): характеристики слева, цена справа sticky —
НЕ столбиком как было.

## Проверка / запуск

`cd repo → npm run dev → http://localhost:3000`. Страница машины:
`/catalog/<slug>` (напр. `/catalog/x5-m60i-sport-pro`).
