# HANDOFF-REBUILD — единый хендоф ребилда (заменяет разрозненные HANDOFF-6…11)

Свод всей информации по **ребилду презентационного слоя** (ветка `rebuild`). Метод-чеклист
для работы — `REBUILD-METHOD.md` (читается автоматически через `CLAUDE.md`). Здесь — стратегия,
механика адаптации и статус по блокам.

---

## 1. Стратегия (согласована)

Собираем презентационный слой **заново по макетам Figma**, чисто, на единых брейках. Начинку
(админка, данные, логика, анимации, токены, примитивы) НЕ трогаем — переписываем только
layout-CSS + разметку. Ветка `rebuild` (локально, не пушено). Старая вёрстка = живой референс
(ветка `mobile-first`, папка `reference/`).

**8 артбордов:** `390 / 480 / 640 / 768 / 960 / 1200 / 1536 / 1920`.
Проверка — **замерами в браузере** (`getComputedStyle`/`getBoundingClientRect`), не на глаз.

## 2. Автоскейл (fluid) — суть ребилда

Резина развёрнута на **mobile-first** И **плавная**: на промежуточной ширине элемент —
растянутая вверх версия нижнего артборда, а не суженная вниз версия верхнего. Значения на
артбордах = **якоря**; между якорями всё растёт **непрерывно** (шрифты, отступы, паддинги,
gap, размеры блоков), без скачка на границе брейка.

**Реализация** (см. `REBUILD-METHOD.md` для формул):
- Готовые fluid-токены `--fs-*` (`styles/typography.css`, 360→1920) — одна непрерывная линия.
- Посегментный `clamp` по якорям — эталон `.t-page-title` (`typography.css:533`) и `--gal-w`
  галереи. `clamp(Vlow, calc(PX + VWvw), Vhigh)` на каждый сегмент `min-width`.

Направление структуры (флип раскладок) — тоже mobile-first (база = мобилка, крупное
добавляется через `min-width` на артбордах, НЕ `481/641`).

## 3. Механизмы / токены

- **`--gutter`** (tokens.css) = 20/20/30/40/40/40/60/60. Контейнер блока:
  `max-width:var(--layout-max); margin-inline:auto; padding-inline:var(--gutter)`. Легаси
  `--page-gutter` и `.car-wrap{padding-inline}` в max-width-тирах — сносим.
- **`--radius-current`** (tokens.css:139) = 12/12/14/16/22/26/30/30 по брейкам.
- **`--fs-*`** (typography.css) = fluid-шрифты 360→1920. **`--type-*`** = фиксированные px
  (использовать только там, где нужен точечный размер без автоскейла — но на страницах ребилда
  предпочитаем fluid).
- Ритм секций: `--section-space`, `--section-space-lg` (глобальные clamp).
- **Общие блоки:** `CarsSection`, `Contacts`, `.about__identity`, `ti-*` (service-kit) —
  единые компоненты, правка расходится на все страницы.

## 4. Что сделано по блокам

**Готово и по методу (fluid):**
- Шапка (`header.css`), крошки (`.ui-crumbs`), футер (`footer.css`), контакты
  (`components/contacts/`), `CarsSection`.
- Услуги: trade-in (эталонный service-kit `ti-*`), лизинг, подбор, помощь, велес, ателье —
  переиспользуют `ti-*` + свои дельты, все на `--gutter`, fluid.
- Главная: кузова «Найдите свой формат», отзывы, блок услуг `.about__identity`, баннеры.
  Hero — точечная починка (см. HANDOFF-11, самый сложный блок, полная инверсия не делалась).
- **Страница машины — галерея** (`car.css`, коммит `89c3c08`): mobile-first + fluid `--gal-w`
  посегментно, наши брейки, радиус `--radius-current`, кнопка/стрелки по краю кадра. ЭТАЛОН fluid.
- **Страница машины — раскладка 1200** (`90094c7`): двухколоночная со sticky-ценой с 1200
  (как 1536, было как 960). `.car-wrap` переведён на `--gutter`.

**Сделано с автоскейлом (fluid шрифты):**
- Заголовок машины (`.car-title`, `a85219e`): развёрнут mobile-first (снесён desktop-first
  каскад + легаси `.car-wrap{padding-inline}` → `--gutter` заработал); имя H1 — fluid
  посегментный clamp (390=20, 414=22.17, 480=28, 768=32, 1200=40, 1536=48). Бейдж/иконки/
  раскладка — шаги (как trade-in).
- Характеристики + комплектация (`.car-specs`/`.car-equipment`): шрифты title/label/value/
  toggle переведены на fluid (посегментный clamp в конце файла, общий блок). Замеры: title
  18→18.94(700)→24(960)→30(1536), label 12→14(960), value 14→16(1536) — плавно между якорями.
  Раскладка/padding/high — шаги (уже по макету, off-by-one 640 в specs починен ранее).

**ДОЛГ (чистка):** дискретный desktop-first каскад font-size/line-height для specs/equipment
(зона `max-width`-тиров + зона типографики `--type-*` + старые `min-width` clamp) остался
МЁРТВЫМ — мой fluid-блок в конце файла его перекрывает. Не удалял за проход, т.к. переплетён
с раскладкой (padding/height/radius в тех же `@media`) — риск сломать. Вычистить отдельно
(убрать только font-size/line-height specs/equipment из тех тиров, раскладку оставить).

**Не тронуто на странице машины:**
- Цена (`.car-price`) — структура 1200 готова, числа/автоскейл не сверены.
- Страхование/гарантия, помощь, ателье (низ карточки) — в том же desktop-first каскаде.
